# RELOD SEO Fixer для 1С-Битрикс

Модуль предназначен для сайта shop.relod.ru на 1С-Битрикс: Управление сайтом 25.600.100 и темы Aspro Premier 1.6.1.

## Главный принцип

Модуль не применяет изменения сразу после загрузки отчёта Netpeak.

Порядок работы:

1. Администратор загружает один XLSX/CSV-файл Netpeak.
2. Модуль определяет тип отчёта и разбирает строки.
3. Модуль показывает найденные проблемы: что найдено, где найдено, текущее значение, предлагаемое значение и риск.
4. Администратор вручную отмечает пункты к исправлению.
5. Администратор отдельно нажимает «Применить выбранные исправления».
6. Перед изменением модуль сохраняет старое значение.
7. Если точное место не найдено или данные изменились после проверки, исправление не выполняется и попадает в журнал «Ошибки и не выполнено».
8. Выполненные изменения можно откатить.

## Что модуль умеет в версии 1.0.0

- Загружать XLSX/CSV по одному документу.
- Определять основные типы отчётов Netpeak по названию файла и заголовкам колонок.
- Создавать карточки проблем.
- Группировать одинаковые причины через group_hash.
- Требовать ручное подтверждение для всех исправлений.
- Применять подтверждённые точные замены только в разрешённых текстовых полях Битрикс:
  - b_iblock_element.PREVIEW_TEXT
  - b_iblock_element.DETAIL_TEXT
  - b_iblock_section.DESCRIPTION
- Сохранять журнал изменений.
- Сохранять отдельный журнал ошибок и пропущенных пунктов.
- Откатывать выполненные изменения.

## Что модуль намеренно не делает автоматически

Чтобы не сломать сайт, модуль не меняет автоматически:

- файлы ядра Битрикс;
- файлы шаблонов Aspro Premier;
- меню и футер, если они хранятся в файлах шаблона;
- canonical;
- slug издателей;
- массовые 301-редиректы;
- SEO-шаблоны title/description/H1 без отдельной доработки под структуру инфоблоков;
- nofollow по всему сайту;
- внешние ссылки;
- скрытые блоки, фильтры, мегаменю, карточки товаров и компоненты каталога.

Такие пункты модуль показывает как требующие ручной проверки или задачи разработчику.

## Установка

1. Скопировать папку `relod.seofixer` в `/local/modules/`.
2. В админке Битрикс открыть «Marketplace → Установленные решения» или список модулей.
3. Установить модуль «RELOD SEO Fixer».
4. Открыть «Сервисы → RELOD SEO Fixer».
5. Первую проверку выполнять только на копии сайта / staging.

## Безопасность

Перед каждой правкой модуль:

- проверяет, что пункт был подтверждён администратором;
- ищет точное старое значение;
- сохраняет старое значение;
- повторно проверяет текущее значение;
- не применяет исправление, если значение изменилось после проверки;
- пишет понятный лог.

## Рекомендуемый сценарий

1. Загрузить первый файл Netpeak, например отчёт по редиректам.
2. Проверить несколько карточек проблем.
3. Отметить 5–10 пунктов к исправлению.
4. Применить.
5. Проверить журнал изменений.
6. Проверить сайт вручную.
7. Запустить повторный Netpeak тем же профилем.
8. Только после этого применять большее количество исправлений.
