# Самопроверка реализации

Проверено по требованиям задачи:

- Все исправления требуют ручного подтверждения.
- После загрузки документа изменения не применяются.
- Загрузка возможна по одному документу.
- Интерфейс показывает: что найдено, где найдено, текущее значение, предлагаемое значение, риск и объяснение простыми словами.
- Есть журнал выполненных изменений.
- Есть отдельный журнал ошибок и пропущенных пунктов.
- Есть откат изменений.
- Есть ограничение количества исправлений за один запуск.
- Резервная копия старого значения обязательна.
- Файлы ядра Битрикс не меняются.
- Файлы шаблонов Aspro Premier не меняются автоматически.
- Canonical, slug, массовые 301, nofollow, тяжёлый HTML и шаблоны не исправляются вслепую.
- Точные замены выполняются только в разрешённых текстовых полях Битрикс.

Что нельзя честно подтвердить без доступа к живому сайту:

- конкретные файлы темы Aspro Premier, где находятся меню, футер, блок издателей и карточка товара;
- структуру инфоблоков shop.relod.ru;
- где именно на сайте хранятся все ссылки из отчётов Netpeak;
- корректность работы на production без предварительного staging-теста.

Поэтому модуль сделан максимально осторожным: если точное место изменения не найдено, он не правит данные и пишет понятную причину в журнал ошибок.
